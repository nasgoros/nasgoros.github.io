Google apps

nasgorOS never includes Google apps. For Play Store and Google services, flash LiteGapps right after the ROM, before the first boot. LiteGapps stays installed after ROM updates.

Install

  1. Unlock the bootloader and install the stock firmware LineageOS requires for your device.
  2. Flash the nasgorOS recovery: fastboot flash recovery NasgorOS-Recovery-17.0-<date>.img
  3. Boot to recovery, Factory reset → Format data.
  4. Apply update and install NasgorOS-17.0-<date>-OFFICIAL-<device>.zip (from storage or adb sideload).
  5. Optional: install LiteGapps.
  6. Reboot. The first boot takes a few minutes.

Coming from an UNOFFICIAL nasgorOS build or another ROM? Format data first. Updates within OFFICIAL builds can be installed over the existing one (no OTA: install new builds from recovery). Flashing is at your own risk.
