## First install

1. Unlock the bootloader with the official Mi Unlock tool.
2. Download the ROM zip and the recovery image above. The firmware (preloader, lk,
   modem) is included in the ROM zip.
3. Reboot to fastboot (**Power + Volume Down**) and flash the recovery:

   ```
   fastboot flash recovery NasgorOS-Recovery-17.0-<date>.img
   ```

4. Boot to recovery (**Power + Volume Up**), then **Factory reset → Format data**.
5. **Apply update → Apply from ADB** and on the computer:

   ```
   adb sideload NasgorOS-17.0-<date>-OFFICIAL-merlinx.zip
   ```

   Or copy the zip to an SD card / USB OTG and choose it in **Apply update**.
6. Optional: install [LiteGapps](https://litegapps.github.io/) now, before the first boot,
   for Play Store and Google services.
7. **Reboot → System**. The first boot takes a few minutes.

## Updating

Install the newer OFFICIAL zip from recovery the same way, without formatting data.
LiteGapps stays installed. Coming from an UNOFFICIAL nasgorOS build or another ROM,
format data first.
